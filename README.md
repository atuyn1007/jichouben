# 记仇本

> 一个纯前端、本地存储的「记仇备忘录」小网站。
> 把每一次不爽都认真记下来，用温度计看着仇恨值慢慢爬满。

在线体验：[https://atuyn1007.github.io/jichouben/](https://atuyn1007.github.io/jichouben/)

---

## 这是什么

记仇本是一个帮你「记账式记仇」的小工具。不是真去害人，是把生活里那些让你不爽的人和事，
像备忘录一样安安静静地记下来——哪天心情好了，再亲手把他们「人淡如菊」。

所有数据只存在你自己的浏览器里（`localStorage`），不上传任何服务器。关掉网页数据不丢，
换设备不共享（这是设计使然，不是 bug）。

---

## 核心功能

### 1. 记仇录入
- 填 **名字** + **备忘录**（当备忘录用，记清楚为啥记这一笔仇）。
- 第一次记一个人，用 **1–100 的温度计滑块**选初始仇恨值，汞柱进度条实时预览。
- 提交即在账本里落一笔，按时间归档。

### 2. 相似检测（防重名 / 防手滑）
- 输入框边打字边 **模糊匹配**：用 Levenshtein 距离 + 包含检测。
- 命中已经记过的人，立刻提示「你之前记过 XX 的仇！当前仇恨值 XX」。
- 命中后继续提交，系统会 **自动给旧账 +10**，而不是另开一本。

### 3. 仇恨累加
- 同一个人 **每多记一笔，仇恨值 +10**。
- 仇恨值到 **100（满级）**，弹出「**忍无可忍 无须再忍**」大字弹窗。
- 首次记录就直接选 100，也会立刻触发该弹窗。

### 4. 分类与展示
- 列表支持两种分组切换：**按日期** / **按自定义分类**。
- 分类可自定义，留空自动归为「未分类」。
- 顶部统计条：在册人数 / 已释然 / 满级人数 / 总记录数，一眼看清你的「仇人版图」。

### 5. 人淡如菊（垃圾桶）
- 手动把想放下的人 **移入垃圾桶**（释然 / 忘了）。
- **自动沉底**：一个人 **连续一个月（30 天）没被记新仇**，自动掉进垃圾桶。
- **自动复活**：一个月后同一个名字又被记仇，系统会把他 **从垃圾桶里提出来**，继续累加仇恨。
- 垃圾桶里可「拉回清算」或「彻底删除」清理。

### 6. 线上复仇
- 输入一个名字，系统随机组合倒霉桥段（**踩到狗屎 / 丢钱 / 没带伞 / 手机掉马桶** 等），
  生成一段幽默的「复仇小故事」让你开心一下。纯娱乐，零实际伤害。

## 使用说明

1. 打开网页（本地双击 `index.html` 或访问上面的在线链接）。
2. 在「记仇」区输入名字、选仇恨值、写备忘录，点提交。
3. 之后每次再记同一个人，仇恨值会自动 +10，满级弹窗。
4. 想放下谁，去「人淡如菊」手动移入；一个月不记的也会自动沉底。
5. 想发泄，去「线上复仇」生成一段倒霉故事。

## 技术说明

- **单文件**：整个应用就是 `index.html`，HTML + CSS + 原生 JS，**零依赖、零构建**。
- **存储**：浏览器 `localStorage`，键名 `jichouben_data`。
- **算法**：字符串相似度用 Levenshtein 距离 + 子串包含判定。
- **隐私**：没有任何网络请求，没有任何后端，数据 100% 留在本地。

git push
