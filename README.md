# 记仇本

一个纯前端、本地存储的「记仇备忘录」小网站。

## 功能
- 记仇录入：名字 + 备忘录，首次用 1-100 温度计滑块选仇恨值
- 相似检测：边打字边模糊匹配，命中已记过的人自动 +10 仇恨
- 仇恨累加：同一个人再记 +10，满 100 弹「忍无可忍 无须再忍」
- 分类展示：按日期 / 按自定义分类分组
- 人淡如菊（垃圾桶）：手动移入、一个月无记录自动沉入、再触发自动复活
- 线上复仇：输入名字随机生成踩狗屎 / 丢钱 / 没带伞等倒霉小故事

## 技术
单文件 `index.html`，零依赖，数据存浏览器 `localStorage`。

## 本地预览
直接用浏览器打开 `index.html` 即可。
